# SAILS — стенд «яхты ↔ зрители» азбукой Морзе

Прототип. Идея: зритель на берегу пишет сообщение на сенсорном стенде, оно
озвучивается азбукой Морзе (и визуализируется осциллограммой сигнала), яхта
(нейросеть через OpenRouter) генерирует ответ и тоже отвечает азбукой Морзе.
Светлый, минималистичный полноэкранный дизайн (16:9 тачскрин).

На стенде три яхты — зритель переключается между ними вкладками вверху панели
и общается с каждой отдельно (своя история, свой характер/системный промпт).

## Архитектура (2 компьютера)

1. **Стенд** (`run.py` + `server/` + `web/`) — работает на компьютере у
   тачскрина, подключённом к Wi-Fi роутеру. Это веб-сервер (FastAPI): отдаёт
   страницу стенда и держит WebSocket-соединения. Именно тут происходит
   обращение к OpenRouter, хранится история диалога и звучит азбука Морзе
   через колонку стенда (через Web Audio API прямо в браузере).

2. **Компьютер на яхте** (`yacht_client/yacht_client.py`) — лёгкий клиент,
   который по Wi-Fi подключается к серверу стенда и получает события «сыграть
   азбуку Морзе». Сейчас он проигрывает звук (`winsound.Beep`) и печатает
   состояние LED в консоль — это заглушка `set_led()`, куда позже подключится
   реальное управление LED-палкой/париком (GPIO/DMX/serial).

Всё это можно запускать и на одном компьютере для тестирования — просто не
запускать `yacht_client.py`, стенд работает и без него.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Впишите свой ключ в `.env`:

```
OPENROUTER_API_KEY=sk-or-v1-...
```

## Запуск

Проще всего — двойным кликом по [start.bat](start.bat): сам создаст
окружение при первом запуске, поставит зависимости, проверит `.env` и
запустит сервер с автооткрытием браузера.

Вручную:

```bash
python run.py
```

Откроется браузер на `http://localhost:8000` — разверните на весь экран
(F11) на сенсорном мониторе.

Компьютер на борту яхты (когда будет готов, укажите IP компьютера стенда в
локальной Wi-Fi сети) — двойным кликом по
[yacht_client/start_yacht_client.bat](yacht_client/start_yacht_client.bat)
или вручную:

```bash
python yacht_client/yacht_client.py --host 192.168.1.10 --port 8000 --yacht yacht1
```

`--yacht` должен совпадать с `id` нужной яхты из `config.json`
(`yacht1` / `yacht2` / `yacht3`).

## Панель настроек — клавиша S

Прямо на стенде, не залезая в файлы, можно на ходу поменять скорость азбуки
Морзе, модель/температуру/длину ответа нейросети, сколько сообщений помнит
история, общий промпт и промпт/имя/значок каждой яхты.

Нажмите **S** (по физической клавише — работает в любой раскладке, ЙЦУКЕН
или QWERTY). Пока курсор стоит в поле ввода сообщения, клавиша S печатает
букву как обычно и панель не открывается — так публика не откроет её
случайно, печатая сообщение яхте.

Кнопка «Очистить историю всех яхт» в панели сразу сбрасывает память всех трёх
яхт (используйте между заездами/сессиями).

Все изменения сохраняются в `config.json` и применяются сразу, без
перезапуска сервера — но если у вас уже открыта вкладка стенда, обновите её
(F5), если правили промпты не через панель, а руками в файле.

## Настройка яхт и промптов вручную

Откройте `config.json`, если хотите править не через панель, а в файле:

- `stand.title` / `stand.subtitle` — заголовок и подзаголовок на экране.
- `yachts` — три яхты: `id` (не менять), `name`, `icon`, `color` (акцент
  вкладки), `system_prompt` (характер).
- `system_prompt_common` — общее правило для всех яхт (сейчас требует
  короткие ответы, т.к. длинный текст долго звучит азбукой Морзе).
- `openrouter.model` — любая модель, доступная на OpenRouter
  (`openai/gpt-4o-mini`, `anthropic/claude-3.5-haiku` и т.д.).
- `max_history_length` — сколько последних сообщений (user+assistant) помнит
  каждая яхта.
- `morse.wpm` — скорость азбуки Морзе (слов в минуту), `morse.tone_hz` — тон
  сигнала.

## Как это работает

1. Зритель выбирает яхту вкладкой вверху и печатает сообщение — встроенная
   экранная клавиатура (ЙЦУКЕН) или обычная клавиатура/тачскрин-ввод.
2. Сообщение сразу переводится в азбуку Морзе (кириллическая таблица,
   `server/morse.py`) и проигрывается на колонке стенда — под сообщением
   рисуется осциллограмма сигнала, которая «зажигается» в такт звуку; текст
   проявляется после того, как сигнал закончил звучать.
3. Параллельно уходит запрос к OpenRouter с системным промптом этой яхты и
   последними `max_history_length` сообщениями её собственной истории
   (`server/history.py`, `server/openrouter_client.py` — логика повторных
   попыток унаследована от референсного модуля `utils/openrouter_api.py`).
4. Ответ яхты добавляется в её историю и точно так же звучит азбукой Морзе на
   стенде — и параллельно уходит клиенту этой яхты (`yacht_client.py`) для
   проигрывания на борту.
5. Сообщения для любой из трёх яхт (даже не открытой сейчас вкладки)
   проигрываются на стенде по очереди из общей очереди — физически колонка
   одна, поэтому сигналы не накладываются друг на друга. На вкладке неактивной
   яхты появляется индикатор новой реплики.
6. Если к серверу подключено несколько дисплеев (например, второй экран для
   тестирования), они все получают одинаковую картину в реальном времени.
